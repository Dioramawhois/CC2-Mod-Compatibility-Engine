# ADR-0021: явный выбор версии одного мода

Статус: реализовано, 2026-11-03. Дополняет ADR-0011/0017/0020.

Локальный кандидат Island Airfields сохраняет Workshop identity 3826940003.
Прежний resolver отклонял весь scan при наличии двух package aliases, даже если
одна версия не выбрана. Это мешало проверить обновление, не трогая подписку.

Source `id` по-прежнему уникален и обозначает конкретную папку. Несколько
источников могут объявлять один canonical `package_id`, но в готовом наборе
разрешена только одна его версия. Явный source selection определяет версию;
зависимости используют её независимо от положения в списке. Если версии не
выбраны и зависимость неоднозначна, resolver требует выбрать одну. Автоматического
предпочтения локальной/новой/Workshop версии нет. Несвязанный identity не может
замаскировать чужой source ID. Cycle/32-package/native/path gates сохраняются.

В GUI галочка другой версии снимает прежнюю до запуска одной транзакции. Если
новая версия отклонена, actual applied selection и прежний payload возвращаются.
Unselected версии не блокируют прочие моды. Отдельных кнопок/подтверждений нет.
Workshop и исходные папки не изменяются. Имя/происхождение источника видны в списке.

Schema v2 не меняется: source id/package_id, hashes и mod_order уже сохраняют
выбранную версию воспроизводимо. Fixtures до реализации: explicit old/local,
невыбранные duplicates, две выбранные версии, dependency до явного выбора,
неоднозначная dependency, shadow identity, реальный fixed-output switch/Undo и
GUI success/rejection с восстановлением галочек. Сообщение переведено на 14 языков.
