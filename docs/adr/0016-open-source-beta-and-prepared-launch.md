# ADR-0016: открытая Windows beta и запуск подготовленного набора

Статус: принято владельцем 2026-11-02; реализация 0.4.0b1.

Владелец выбрал GPL-3.0-or-later и попросил запускать игру с уже включёнными
изменениями. Это новая версия существующего CC2 ModLoader: executable,
owner/schema identities и постоянный output не меняются. Новые Workshop items
для ModLoader, CC2X или Island Airfields этим решением не создаются.

В меню добавлен сохраняемый флаг «Запускать игру при открытии». По умолчанию
выключен. При открытии приложение сначала сканирует, проверяет и при необходимости
транзакционно активирует выбранный набор, затем использует обычный запуск Steam.
Переключение самого флага не запускает игру. Отказ применения отменяет автозапуск:
нельзя незаметно запустить предыдущий набор вместо отклонённого. При работающей
игре сохраняется отсрочка. После успешного запуска окно закрывается, кроме набора
с предупреждением о перезаписи: его сообщение остаётся доступным. Внутренний
`--play` использует тот же путь и нужен интеграциям, не пользовательской инструкции.

Полный интерфейс внутри игры не реализован: у CC2X не доказан ресурсный merge hook,
а Python/Tk и Git нельзя объявить доступными в игровом Lua. Сначала требуется
проверенный bootstrap и протокол между нативным UI и существующим merge backend.
Никакого изменения vanilla executable или автоматического доверия DLL.

Публичная поставка — явно Windows beta, не завершённый Windows/macOS MVP.
Включены GPL-текст, NOTICE, лицензии runtime, SBOM и публичный build report без
локальных путей/содержимого модов. Исходники приложения, точные исходники Git/Lua
и зависимостей с build recipes, закреплённые инструменты и SHA256SUMS публикуются
на той же странице. Источники фиксируются по хешу; mutable upstream patch не
принимается вместо исходника с ожидаемым хешем.

Сборка из чистого checkout получает готовые инструменты по зафиксированному SHA,
без приватного SDK-пути. Неизвестные пути, links и повреждённые архивы отклоняются
до записи. Это developer download, не скачивание зависимостей при старте у игрока.
Release packager требует clean commit, соответствие binary/source hashes и
проходящий JUnit, публикует assets атомарно через отдельный staging-каталог.

Регрессии: запуск после фактической активации, отмена после отказа, совместимость
старых preferences, privacy projection и unsafe/tool archive отказ до записи.
Эти тесты и frozen GUI smoke не заменяют игровой/network acceptance.
