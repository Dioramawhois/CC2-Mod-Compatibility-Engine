# ADR-0022: статус сборки SDK вне интерфейса ModLoader

Статус: принято, 2026-11-03. Уточняет UI-часть ADR-0020 по прямому запросу владельца.

ModLoader управляет выбором, слиянием и активацией модов. Сведения о тестовой
сборке SDK и непроверенных игровых режимах относятся к отдельному продукту SDK.
Они не создают banner, заголовок, подробности предупреждения или иное постоянное
уведомление в ModLoader, даже если активный manifest содержит runtime_review.
Соответствующие сообщения удаляются из offline UI catalogs.

Технический контракт не меняется: optional runtime_review schema v2 сохраняет
stage, source/version, verified/unverified scopes и evidence hash. Отсутствие
SDK notice не означает прохождение новых gameplay/network/platform проверок.
Эти границы остаются в документации SDK и отчётах приёмки.

Предупреждение о реальной перезаписи изменений по ADR-0014 сохраняет участников,
ресурс, порядок и сообщение о неизвестном результате в игре. Native hash/profile,
path/syntax и transactional gates остаются обязательными.

Регрессии: runtime_review без override не создаёт GUI warning; с override остаётся
только предупреждение о перезаписи; восстановленный manifest и смена языка не
возвращают SDK notice. JSON schema и SDK/DLL bytes не изменяются.
