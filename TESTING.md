Python, Git, Lua и терминал игроку не нужны. Проверяйте установленный `CC2ModLoader.exe` рядом с игрой.

1. Убедитесь, что игра найдена, Workshop моды отображаются с названиями, а верхняя строка показывает текущий активный набор. mods/libraries создаются автоматически. На основном экране нет кнопок подготовки, поиска, применения или экспорта; служебные действия находятся в меню.
2. При закрытой игре отметьте **AI Bridge** и **Island Airfields**. Без дополнительных кнопок/подтверждений дождитесь «Готово. Можно запускать игру». Для проверенной сборки 1.5.18 r2 обе правки сохраняются в одном скрипте, DLL не теряется.
3. Если runtime ещё отсутствует, поддержанный dinput8.dll должен быть предоставлен в libraries. Неизвестный существующий loader нельзя перезаписать.
4. Переключите набор. Ожидается та же папка пользовательского `mods/CC2-MCE` и игровое имя «CC2 Engine — мои моды»; снятые ресурсы не остаются. При конфликте новая галочка должна сняться, прежние галочки/payload остаться, запуск рабочего набора доступен. У отказанного мода названы участники; файл виден через меню подробностей. Пассивный scan не стирает отказ. Снятие всех галочек отключает моды. Источники игры/SDK/Workshop сохраняются.
5. Запустите игру из приложения. В новом сеансе проверяются меню/отсутствие Lua errors, затем отдельно экран управления, обе функции и посадка/выход из сохранения. Запуск меню не равен доказательству всех игровых функций.
6. После закрытия игры выберите «Меню → Вернуть предыдущий набор». Восстанавливаются payload и активация, галочки отражают возвращённый состав. Форматирование и повторённый игрой тот же path не должны ломать rollback; другой реально выбранный вне Engine набор нельзя затирать автоматически.
7. Измените галочки при открытой игре: запись ожидает закрытия, затем продолжается автоматически. Неприменённый/конфликтующий выбор нельзя запустить из приложения как готовый. Обновлённый выбранный source должен автоматически пересобираться; новый найденный мод остаётся без галочки.

8. Если снять обязательную зависимость, она останется включённой с пояснением, какому моду нужна. При ошибке записи новый выбор отменяется с причиной; неизвестное состояние/pending transaction не разрешает launch. Для недоступной папки при первом запуске нет обхода проверки или перезаписи чужого файла.

## 0.4.0b1 regression scope

Added GUI coverage proves launch observes the activated selected payload, and a
rejected selection never starts the old set. Preferences cover old-file defaults
and invalid types. Release/tool tests cover privacy, source filtering, exact archive
hashes and malicious ZIP names before writing. These are offline/GUI tests, not
multiplayer, in-game UI, dedicated-server or clean-machine acceptance.
