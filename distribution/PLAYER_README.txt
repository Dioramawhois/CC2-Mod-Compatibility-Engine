CC2 ModLoader 0.4.0 beta 1

English
1. Extract this archive. Put CC2ModLoader.exe next to carrier_command.exe
   (Steam > Carrier Command 2 > Manage > Browse local files).
2. Open CC2ModLoader.exe and select your mods. Checkboxes apply changes
   automatically; changing Load order rebuilds the same output folder.
3. Wait for Ready, then select Launch game. You can enable
   Menu > Launch game when opening ModLoader for subsequent starts.
   An override warning means the in-game result is unknown: inspect it.

No Python, Git, Lua or terminal is required. Workshop downloads remain intact.
The selected packages are combined locally; they are not uploaded anywhere.
Unsupported native DLLs remain blocked. Existing unknown loaders are not replaced.
Close the game before changing the active set. Undo is available in the menu.

This Windows beta includes source provenance, licenses and checksums.
Full gameplay compatibility, clean-machine certification, the packaged macOS app,
in-game ModLoader UI and Island Airfields multiplayer are not certified here.
This release updates the existing ModLoader; it creates no new Workshop item.

Source, issues and updates:
https://github.com/Dioramawhois/CC2-Mod-Compatibility-Engine

Exact Git/Lua sources and toolchain are separate assets on the same release page.

Русский
1. Распакуйте архив. Положите CC2ModLoader.exe рядом с carrier_command.exe
   (Steam > Carrier Command 2 > Управление > Посмотреть локальные файлы).
2. Откройте приложение и отметьте моды. Галочка сразу применяет изменения,
   смена порядка пересобирает ту же папку. Дождитесь готовности.
3. Нажмите «Запустить игру». Для следующих запусков можно включить
   «Меню > Запускать игру при открытии». При перезаписи чужих изменений
   прочитайте предупреждение: результат в игре неизвестен.

Ничего устанавливать через терминал не нужно. Во время изменения набора
игра должна быть закрыта. Предыдущий набор возвращается через меню.
Это Windows-бета существующего ModLoader. Мультиплеер аэродромов,
интерфейс внутри игры, чистая ОС и готовая macOS-сборка здесь не подтверждены.
