# ADR-0014: постоянное предупреждение о перезаписи и граница Workshop

- **Статус:** Accepted для предупреждения и аудита; публикация/новый installer не выполнены.
- **Дата:** 2026-11-02
- **Основание:** владелец попросил вернуть предупреждение о несовместимости и провести полный аудит Steam-зависимостей.

## Предупреждение

`overridden` означает сознательное разрешение пересечения по порядку, а не доказанную игровую совместимость. Один счётчик замен недостаточен. Успешный apply показывает постоянный оранжевый banner: названия участников в порядке merge, первый ресурс, число остальных ресурсов и явное сообщение, что результат в игре неизвестен. В меню доступны все ресурсы, порядок участников и различие между Git hunk merge и заменой файла целиком. Участники отмечены в списке как включённые с перезаписью.

Это неблокирующее предупреждение: успешная галочка сохраняется, запуск доступен, новых кнопок/подтверждений нет. При reorder предупреждение обновляется. При удалении последнего пересечения исчезает. Passive scan и повторный запуск восстанавливают его из активного собственного manifest, включая запуск без новой сборки. Ошибка следующего запроса имеет приоритет в banner и возвращает фактический рабочий набор; следующий успешный результат снова показывает его предупреждение, если нужно.

Проверка опирается только на report.files со status=overridden. Общий путь, identical или clean three-way сами по себе не называются несовместимостью. Варианты `git-three-way-later-hunks`, `ordered-replacement-no-base`, `ordered-binary-replacement` различаются в подробностях. В N-way не утверждается, что последний мод заменил каждую правку каждого участника: показывается реальный порядок и существование разрешённого пересечения.

Контракт package v2 и алгоритм merge не изменены: те же status/strategy/source hashes/mod_order; предупреждение — их локализованная проекция. Все 14 каталогов включают новые сообщения. Fixtures до реализации проверяют названия/порядок, uncertain result, whole-file wording, ограниченный banner/полные подробности, отсутствие false positive, сохранение/восстановление/очистку warning и доступность запуска.

## Распространение

Принята практическая архитектура из [аудита](../19-STEAM-DISTRIBUTION-AUDIT.md): один GUI bootstrap вне Workshop, Workshop-библиотеки и авторские моды с нашей XML dependency секцией. Required Items Steam и requires в mod.xml — два разных уровня. Публикация item не устанавливает bootstrap автоматически. Отдельное Steam Player Tools приложение — перспективный канал после согласования с Valve и получения собственного AppID; подмена AppID игры не допускается.

Этот ADR не даёт разрешения загружать публичный item, использовать чужие Steamworks права, копировать game assets или включать Steamworks SDK в GPL код. Приложение и CC2X runtime остаются отдельными бинарниками; плагины не «вплавляются» в общий injector. Шаблоны публикации содержат только собственные metadata, без DLL/игровых ресурсов и без выдуманного item ID.
