## Границы

Отказ не выбирает победителя и не выключает уже работавший мод ради нового. Проверка Git/Lua/native/baseline остаётся fail-closed; исходники не меняются. Папки создаются только внутри проверенной игры, portable из неверного места ничего не создаёт. При обновлении исходников прежняя активная версия сохраняется до успешной сборки, даже если галочки возвращены.

Проверка исправлений: regression fixtures на настоящий Git и реальные Tk widgets, первый запуск и недоступный каталог, ошибки применения, быстрые изменения, запуск прежнего набора после отказа, сохранение объяснения при пассивном scan, меню без служебных кнопок. Windows frozen GUI проверяется отдельно; эти UI-проверки не являются gameplay или macOS execution acceptance.

Локальные результаты 0.2.2: 168 tests passed, 3 symlink skips; Ruff/mypy Windows и darwin static analysis. Pure presenter и настоящие Tk widgets проверяют названия/ресурс, снятие отказанной галочки, доступный launch, сохранение payload, ошибки записи, обязательные зависимости и создание папок. Synthetic preview `build/ux-conflict.png` визуально показывает inline отказ/неотмеченный мод и доступный запуск. Исходники установленных модов для этих сценариев не редактировались.
