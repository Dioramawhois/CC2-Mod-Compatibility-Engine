## Обнаруженная несовместимость ABI

В Native Bridge публичный `cc2x_api` имеет версию 8. Его хвост API 5 начинается
с `active_mod_count`, `active_mod_path`, `patch_bytes`; дальше находятся native
operations и `lua_add_global`. В нашей первоначальной ветке 0.6.0-dev на API 5
оказались `session_generation` и `server_post_session`. Проверка только
`api_version >= 5` и минимального размера пропускает чужую раскладку: вызов
попадает в функцию с другой сигнатурой. Допускать такую комбинацию нельзя.

Исправление в существующих SDK/Island Airfields MR:

- Общий `cc2x_api` оставлен с прежним префиксом API 4.
- Сессионные функции вынесены в именованное расширение
  `cc2x_query_session_v1`; проверяются interface ID, версия, размер и callbacks.
- Адрес query ищется только в модуле, которому принадлежит callback ядра.
  Отсутствующее расширение оставляет плагин неактивным. Чужие tail slots не читаются.
- Queue regression покрывает смену сессии, повторное использование адреса,
  устаревшее поколение, FIFO и отсутствие сервера. ABI regression покрывает
  отсутствующий query, неправильные ID/version/size/callbacks.

Компилятором дополнительно сверены 66 смещений полей общего API и 85 значений
enum переданной копии Bridge; это compile-only проверка, код Bridge не запускался.
В SDK добавлен `tests/check_reference_prefix.py` для повторения с явным путём
к стороннему заголовку. Совпадение префикса не разрешает читать неизвестный хвост.

Это не объявляет готовую Bridge DLL совместимой. Её отдельные native features
и runtime fingerprint требуют собственной проверки. Две разные `dinput8.dll`
не могут одновременно занимать один путь: дальнейшая интеграция должна дать
одно согласованное ядро существующего SDK, а не второй параллельный инъектор.

## Применение примера Hold к аэродромам

Наша функция обработки нового посадочного waypoint меняла/очищала приказ без
явного вызова `waypoints_sync` после своей правки. Прямой запрос и отложенное
завершение уже отправляли обновление. Отправка принятого результата теперь
централизована после очистки списка; при отказе/ожидании отправляется итоговый
обычный move waypoint. Лишние дубли из прямого/отложенного пути удалены.

Регрессия компилирует фактический production handler с тестовыми API-значениями:
принятие, отказ, ожидание острова, отложенное выполнение, прямой запрос и
обычный неизменённый move. Проверяется однократная публикация после изменения.
Это проверка вызовов и порядка действий, не доказательство получения пакета
гостем. Отдельно остаются docking/physics replication и late join.

Ни сообщение кнопки 20, ни неизвестные смещения из чужой игры не скопированы
в наш flight director. Использован уже имеющийся штатный waypoint broadcast
SDK. Алгоритм полёта остаётся в текущей версии Island Airfields.

## Лицензии и происхождение

`carrier-command-2-mods/CREDITS_ET_LICENCE.md` явно распространяет собственные
plugins, Lua/Python и исследования по GPL-3.0-or-later; notices/авторство должны
сохраняться при заимствовании. Игра и сгенерированные из её ресурсов файлы туда
не входят. Источник: [закреплённый commit](https://github.com/totolerigolo118/carrier-command-2-mods/tree/174f3317e8790e244d89cd9ccdcc4c339d956769).

`Native Bridge/NOTICE.md` указывает GPL для vendored CC2X и MIT для Lua, но для
собственного Bridge/aircraft assets говорит: «No new license is assigned by this
source export». Общей явной лицензии на перенос собственного C++/SDK/asset кода
в переданной копии нет. Поэтому эти реализации сейчас изучались, не вендорились
и не публиковались в наших репозиториях. Отсутствие LICENSE не мешает независимо
исправить собственный код по обнаруженному несовпадению контрактов.

## Следующие обязательные проверки

1. Обычный host: приказ от гостя, проверка команды хостом, общий результат у двух
   игроков; принятие/отказ/отмена, разные команды, отключение и переподключение.
2. Проверить, какие docking/physics изменения движок рассылает автоматически,
   а для каких требуется дополнительная подтверждённая операция SDK. Не обещать
   исправление этого класса данных только по успешному waypoint broadcast.
3. Dedicated: подтвердить профиль/world layout и способ запуска SDK. В текущем
   dedicated executable нет dinput8/GLFW import; материалы не дают готового
   проверенного dedicated bootstrap. Клиентские адреса не подставляются.
4. Сохранение/загрузка и late join должны восстановить те же самолёты/очереди.
5. До переноса собственных Bridge реализаций прояснить условия их публикации.

Существующие ID/названия/Workshop items сохраняются. Эти изменения находятся
в development MR SDK и Island Airfields. Публичная ModLoader 0.4.0b1 не менялась
и непроверенные новые DLL в установленную игру не устанавливались.
